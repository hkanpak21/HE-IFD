# Issue briefs

One file per task, written so that an agent with no conversation history can pick
it up. Each brief points at `docs/plan/paper-rewrite.md` for the current plan and
at `CLAUDE.md` for how to run compute.

Naming: `<slug>.md`, lowercase, no dates.

Briefs whose work has landed, or which describe a superseded method, live in
`docs/archive/issues/`. The live task list is the experiment table in
`docs/plan/paper-rewrite.md`.
