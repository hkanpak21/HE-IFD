## What this round is

The PIs read the manuscript on Overleaf and left margin comments between
11 and 17 August. Alptekin Kupcu commented on 11 and 12 August, Sinem Sav on
17 August. This file is the record of that round, in the four field form the
folder README sets: where the comment sits, the comment as the PI wrote it, why
it was made, and the replacement text or the status.

The raw export of the comments lived at `docs/PI_comments_on_2026-08-19.md` and
was moved here on 2026-08-20. Nothing was cut. Every comment in the export has
an entry below.

This round differs from 2026-08-06 in one way. The comments were triaged into
numbered items in `docs/plan/paper-todo-2026-08-19.md` first, and the
replacement text lives in the paste files under `pastes/`, one per item group.
Each entry below therefore names the item that owns it and the file that holds
the text, rather than repeating the text here. Where an entry says a comment is
still open, no text exists for it yet.

Comments in Turkish are quoted as written, with a short gloss.

**Read this file before touching any section it covers.**

Voice rules for every replacement in the paste files: the `academic-ste`
register. No first person, no em dash, no en dash except between numerals, one
idea per sentence, and no number that has not been checked against a record
under `results/`.

## Note 1. The abstract says too little about results

**Location.** `main.tex`, the abstract, the closing sentences beginning "Across
four text classification tasks".

**What the PI wrote.**

> akupcu
> 11 August, 3:21 pm
> could we put more about results? performance during fine tuning? against normal FL?

Anchored on:

```latex
costs $0.04$ to $0.14$ accuracy against a disclosed model, and $5$\,MiB of traffic per query.
```

**Why the comment was made.** The abstract states the accuracy charge against a
disclosed model and the traffic, and nothing about what the protocol adds over
the alternative a reader already knows, which is cryptographically secure
multi-round federated learning. Clarified with the user on 2026-08-19: "against
normal FL" means against cryptographically secure FL, on security, privacy and
accuracy, and it is not a request for new experiments.

**Status.** Item T13. Replacement text in `pastes/T35-intro-abstract.md`. The
answer is one sentence built from figures the introduction already carries,
including POSEIDON's own numbers. Note that the abstract line quoted above has
since changed. The manuscript now reads "$0.03$ to $0.14$", corrected on
2026-08-19 from the record, see note 1 of `PI_notes_2026-08-06.md`.
