\caption{HE-IFD. A frozen public backbone $\varphi$ and a public initialization $\theta_0$ are shared by all
clients and carry no data, so there is no alignment phase. Each client fine-tunes a small adapter on its own
private data $\mathcal{D}_j$ for a bounded number of steps from $\theta_0$ and encrypts the resulting
displacement $\Delta_j$. The server's sole operation is the sample-weighted linear combination
$\theta^\star=\theta_0+\sum_j w_j\Delta_j$ under multiparty CKKS (additions and public-scalar
multiplications only; multiplicative depth one); it never decrypts. A threshold of clients jointly decrypts
the global model $\theta^\star$.}
